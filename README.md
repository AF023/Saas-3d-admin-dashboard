# 🛸 Futuristic 3D SaaS Financial & Executive Admin Dashboard

[![Live Demo](https://img.shields.io/badge/Live_Demo-Interactive_3D_Site-00F2FE?style=for-the-badge&logo=github)](https://af023.github.io/Saas-3d-admin-dashboard/)

## 📌 Overview
This project is an ultra-modern, high-performance **SaaS & Financial Executive Admin Dashboard** built with custom front-end technology. It features an interactive **Three.js WebGL 3D canvas**, real-time data visualizers (Chart.js), dark mode glassmorphism visual styling, dynamic bilingual internationalization (PT/EN toggle), and responsive user interaction logic.

Designed to demonstrate modern UI/UX engineering standards, micro-interactions, and real-time state management for web applications.

---

## ✨ Key Features
- **WebGL 3D Interactive Centerpiece:** Animated floating glass icosahedron with concentric wireframe rings, data particle node systems, and cursor parallax physics powered by **Three.js**.
- **Dark Glassmorphic UI/UX:** Built with custom Tailwind CSS styling, frosted backdrop blur filters, and neon status indicators.
- **Dynamic Internationalization (i18n):** Real-time language toggle (English / Portuguese) allowing seamless switching across all UI text elements and placeholders.
- **Dynamic Data Visualization:** Real-time revenue trajectory area charts and performance metrics via **Chart.js**.
- **Interactive State Controls:**
  - **Live Payment Simulation:** Triggers real-time MRR, subscriber, and total revenue state updates alongside 3D pulse wave particle bursts and dynamic transaction row insertions.
  - **3D Rotation & Camera Controls:** Toggleable auto-spin and WebGL viewport reset functions.
  - **Instant Table Filter:** Real-time search bar for filtering recent subscription transaction streams.

---

## 🛠️ Tech Stack
- **Structure & Markup:** HTML5 (Semantic & Accessible).
- **Styling & Layout:** Tailwind CSS (CDN), Custom CSS Variables, Glassmorphism Backdrop Blur.
- **3D Graphics & Physics:** Three.js (WebGL rendering, particle systems, geometry transformations).
- **Data Charts:** Chart.js (Custom gradient fills & responsive canvases).
- **Icons:** Lucide Icons.
